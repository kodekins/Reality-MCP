Build Reality MCP

Build a production-quality MVP called Reality MCP.

Reality MCP turns any phone, laptop webcam, or eventually CCTV/IP camera into a searchable physical-world sensor that AI assistants such as ChatGPT can query through MCP.

The core concept is:

Camera → Visual Understanding → Structured World State → Temporal Memory → Events → MCP → ChatGPT

This is NOT a normal surveillance dashboard.

The primary product goal is to create a persistent Physical World State Layer for AI agents.

A user should eventually be able to ask ChatGPT things such as:

* What is currently on my desk?
* How many Coke cans are visible?
* Where was my laptop last seen?
* What changed during the last hour?
* Is anyone waiting at reception?
* When did this object disappear?
* Which shelf is low on stock?

For this MVP, focus on browser/mobile camera input and API-based image understanding. Do NOT require a local GPU.

Suggested approach:

* resize images
* compare current image against previous image
* compute a lightweight visual difference score

If change is below configurable threshold:

do not invoke AI.

send the frame for semantic analysis.

6. VISION ANALYSIS

Create a service:

visionService

The AI should convert the camera frame into structured JSON.

Return approximately this schema:

{
  "scene_summary": "A desk containing a laptop, mouse and two beverage cans.",
  "objects": [
    {
      "label": "coca cola can",
      "category": "beverage",
      "count": 2,
      "confidence": 0.91,
      "attributes": {
        "color": "red"
      }
    }
  ],
  "people_count": 0,
  "important_observations": [],
  "uncertainties": []
}

Ensure JSON validation with Zod.

Never trust malformed AI output.

If parsing fails:

* retry once
* otherwise store an analysis failure
* do not corrupt world state

Use low-cost image detail appropriate for MVP.

Compress and resize images before sending them to AI.
